# PerRoute 3.6.0

PerRoute comes to the browser: a new extension for Chrome, Edge, Brave and Vivaldi routes sites the way the app routes programs, with or without the app. The desktop app gets Quick Route from Explorer, LAN Bridge for your other devices and resource saving on battery, and a new installer lets you choose what to install.

## Downloads

| File | Description |
|---|---|
| `PerRoute-Setup-3.6.0.exe` | Full installer. Choose the app, the browser extension or both. One Administrator approval installs everything you chose. |
| `PerRoute-Portable-3.6.0.zip` | Portable build of the app. Extract and run `PerRoute.exe`. |
| `update.json` | Signed update manifest. PerRoute reads it from the latest release by itself; keep it attached. |

**Requirements:** Windows 10 or 11, 64-bit. No Java installation is needed. The extension needs a Chromium browser (Chrome, Edge, Brave or Vivaldi).

## New

### Browser extension

Where the app routes Windows programs, the extension routes sites, and it works without the app.

- **This site.** The toolbar button shows where the current site goes. One click sends it through the tunnel, directly or nowhere, for good or for 15 minutes to 4 hours, through the main server or one of its own.
- **Servers.** VLESS, VMess, Trojan and Shadowsocks from subscriptions, links, Xray JSON and QR codes (also from the camera or the current page). Real tests through each server, quality scores with a breakdown, tags, bulk tests, removal of failed servers, and automatic failover.
- **Try a server for a while,** then go back to the previous one by itself.
- **Rules.** Sites, IP ranges, ports and patterns; everything through the tunnel or only selected sites; local names stay local. A rule tester, a warning for rules that never apply, presets with a preview, recipes as files, and Undo.
- **Protection.** Kill switch, WebRTC protection, and DNS resolved on the server for tunnel sites. The kill switch holds tunnel sites offline while direct sites and local names keep working.
- **Subscriptions.** Usage, quota, expiry and update history, with warnings and notifications when one has expired, is used up, fails or changed a lot.
- **Doctor and inspector.** Checks the runtime, the server, the live route and the exit address, shows every host a tab contacts, and routes a single host from there.
- **Shortcuts.** A right-click menu on pages and keyboard shortcuts to connect, switch the current site or use the fastest server.
- **Profiles, traffic totals and password-protected backups** with Undo.

To install it, run `PerRoute-Setup-3.6.0.exe` and choose **Browser extension**. The installer puts the runtime in `C:\Program Files\PerRoute Browser`, registers it with your browsers and shows the last step: open the extensions page, turn on Developer mode and choose **Load unpacked** with the `extension` folder.

### Quick Route

- **Route with PerRoute** in Explorer's right-click menu for programs and their shortcuts. Turn it on in *Settings > General*; it is registered for your Windows user only.
- A small window picks the main server, a server of its own, Auto or no route. While connected, it saves and reconnects once.
- Starting PerRoute a second time brings the running window forward.

### LAN Bridge

*Tools > LAN Bridge* shares this computer's connection with a phone, tablet or TV on the same Wi-Fi, through the main server.

- For an hour, four hours or until you stop.
- Each device gets its own port, a random password and a setup code, shows its recent activity, and can be removed on its own.
- PerRoute listens only on the private network you choose. The one-time firewall rule is limited to private networks and PerRoute's bundled core, and shared devices cannot reach this computer or your local network.

### Resource saving

*Settings > Automation*, on by default. On battery or a metered network, background server checks run hourly on fewer servers, automatic speed tests pause and updates wait. Routes, route recovery and the kill switch are never weakened.

### New installer

A redesigned installer asks whether you want the app, the browser extension or both, and registers the extension's runtime with every Chromium browser it finds. The uninstaller removes either part, and also removes the **Route with PerRoute** menu entries and the LAN Bridge firewall rules. Your servers, settings and LAN Bridge devices stay in the data folder.

## Fixed

- Settings rows and the Simple sidebar fit the smallest window.

## Upgrading

PerRoute 3.5.1 finds and installs 3.6.0 by itself: choose **Restart and update** when it asks, or check now in *Settings > Updates*. Your servers, apps, routes and settings are kept, and the version it replaces is kept for a rollback. The automatic update updates the app only; to add the browser extension, run `PerRoute-Setup-3.6.0.exe` and choose **Browser extension**.

From 3.0.0 or earlier, download the installer and install 3.6.0 by hand this one time.
