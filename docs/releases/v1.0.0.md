# PerRoute 1.0.0

The first stable release of PerRoute, a Windows client that routes only the applications you choose through VLESS, VMess, Trojan or Shadowsocks servers.

## Downloads

| File | Description |
|---|---|
| `PerRoute-Setup-1.0.0.exe` | Full installer. One Administrator approval installs PerRoute and the per-app engine. |
| `PerRoute-Portable-1.0.0.zip` | Portable build. Extract and run `PerRoute.exe`. |
| `update.json` | Signed update manifest used by *Settings > Secure updates*. |

**Requirements:** Windows 10 or 11, 64-bit. No Java installation is needed.

## Highlights

- Smart per-app, System proxy and Local proxy connection modes
- Subscriptions by URL, share links, Xray JSON and QR code
- Latency, real tunnel and download speed tests with automatic testing of the best servers
- Live server switching, auto reconnect, auto failover and a per-app kill switch
- Per-application routing rules by domain, IP/CIDR and port
- One-click Work, Gaming and Streaming scenarios, plus saved profiles
- Privacy & routing inspector for exit IP, DNS and rule verification
- Traffic history with a live speed graph and per-application totals
- Quick Access tray panel
- Encrypted local state with a DPAPI-wrapped key
- Automatic restoration of Windows proxy settings after a crash, forced close or sudden restart
- Signed, hash-verified updates

## Upgrade note

The settings key is bound to your Windows account on first start. After upgrading, earlier builds can no longer read the saved settings, and the settings file cannot be moved to another Windows account or machine.

## Enabling automatic updates

Enter this feed once in *Settings > Secure updates*:

```
https://github.com/AliMirzad/PerRoute/releases/latest/download/update.json
```
