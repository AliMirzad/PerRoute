# PerRoute 2.0.0

A redesigned interface and an optional server per application.

## Downloads

| File | Description |
|---|---|
| `PerRoute-Setup-2.0.0.exe` | Full installer. One Administrator approval installs PerRoute and the per-app engine. |
| `PerRoute-Portable-2.0.0.zip` | Portable build. Extract and run `PerRoute.exe`. |
| `update.json` | Signed update manifest used by *Settings > Updates*. |

**Requirements:** Windows 10 or 11, 64-bit. No Java installation is needed.

## New

- **A server per app (Advanced routing).** Selected applications can use their own server while the rest follow the main server. It is off by default; turning it off keeps your choices and simply stops applying them. Any saved server can be chosen, including embedded Xray JSON profiles with their own balancers and rules.
- **New navigation.** Eight labelled sections replace the icon buttons and overlays: Connection, Apps, Servers, Rules, Profiles, Diagnostics, Traffic and Settings.
- **Connection** shows one row per server in use, with the applications on it and the result of that server's own last check.
- **Add servers** previews what a subscription URL, pasted links or a QR code contain, including entries that could not be read, before anything is saved.
- **Rules** can be edited and reordered. Proxy sends a connection through the application's own server.
- **Presets** show exactly what they would change before you apply them.
- **Diagnostics** checks every route separately, marks results older than five minutes as stale, and predicts which rule and server a destination would get.
- **Traffic** adds totals for today, per day and per application.
- **Tags in one click.** Every server row has a tag button that lists your existing tags; favorites and tags are shown as badges on the row.
- **Reset everything** in *Settings > General* returns PerRoute to its initial state.
- A refreshed logo that matches the interface colours.

## Changed

- The main server is chosen explicitly with **Use as main server**. Clicking a server only selects it.
- Changes on the Apps screen are staged until **Save changes**; leaving with unsaved edits asks first.
- The app selection, app routes, rules, presets and profiles can only be changed while disconnected.
- Quick Access lists the servers in use first, then favorites. Quit moved to its overflow menu.
- Scenarios are now called presets.
- Settings are grouped into General, Connection, Automation, Updates, Components and Activity log.
- A server switch is validated by Xray before the running connection is touched, and rolls back if the new one does not start.

## Good to know

- All servers share one Xray process. Switching the main server, including automatic failover, briefly interrupts applications on custom servers as well.
- Custom servers are not failed over automatically and apply in Smart per-app mode only.
- If an application's custom server is removed, PerRoute asks for a replacement instead of moving the application to the main server or to the direct route.
- When a custom server is an embedded Xray profile, DNS and policy settings come from the main server, because Xray has them only once per process.
- If Xray rejects a server's own configuration, PerRoute does not connect and names that server.

## Upgrade note

Settings, servers, favorites, tags, rules and profiles from 1.0.0 are kept. Advanced routing starts switched off, so an upgraded installation routes exactly as before until you turn it on.

The update signing key changed with this release. PerRoute 1.0.0 will not accept the 2.0.0 update manifest, so install 2.0.0 once by hand; from then on updates are found automatically again.

## Enabling automatic updates

Enter this feed once in *Settings > Updates*:

```
https://github.com/AliMirzad/PerRoute/releases/latest/download/update.json
```
